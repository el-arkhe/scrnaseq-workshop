## Mas datos scRNA-seq

Existen múltiples datasets de **snRNA-seq humano** disponibles públicamente. Los siguientes datos son accesibles mediante **Globus Endpoints**, un sistema ampliamente utilizado para compartir datos desde cero  hasta resultados procesados.


### Proyectos de referencia

#### 1. 10xPilot_snRNAseq-human

Proyecto de **single-nucleus RNA-seq (snRNA-seq)** con datos de **ocho donadores postmortem**, generado por el **Lieber Institute for Brain Development**.

- Regiones cerebrales:
  - NAc
  - AMY
  - sACC
  - DLPFC
  - HPC

Repositorio GitHub:  
https://github.com/LieberInstitute/10xPilot_snRNAseq-human
